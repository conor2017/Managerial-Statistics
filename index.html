CI = estimate ± z × SE Lecture 6 supplies the SE (σ/√n, from the CLT). Every formula after it is this one sentence with a different estimate and a different SE. If the interval misses the reference value, the result is significant at that level. The p-value is just the confidence level where the interval first touches the reference value.

What the slider is doing

The interval is estimate ± z × SE. Confidence level is the area of the normal curve between minus z and plus z. The test statistic is (estimate minus reference) divided by SE, and the p-value is 2 × P(Z ≥ |test statistic|). When the slider z equals the test statistic, the interval edge sits exactly on the reference line.

Step zero: the CLT facts (Lecture 6)

E[X̄] = µ   Stdev(X̄) = σ / √n

If the Xᵢ are independent with the same mean and standard deviation, then for n ≥ 30 the sample mean is approximately Normal with those two parameters, whatever shape X itself has. σ/√n is the standard error.

P(estimate off by more than d) = 2 × P(Z ≥ d / SE)

Lecture 6 NPS: σ = 0.8, n = 200, SE = 0.0566, so P(off by more than 5 points) = 2 × P(Z ≥ 0.88) = 37.9%. At n = 1,000 it drops to 4.8%. A confidence interval is this question run backwards: fix the probability, solve for the distance.

All four standard errors

Mean: SE = s / √n
Proportion: SE = √( p̂(1 − p̂) / n )
Diff in means: SE = √( s²ₓ/nₓ + s²ᵧ/nᵧ )
Diff in proportions: SE = √( p̂₁(1−p̂₁)/n₁ + p̂₂(1−p̂₂)/n₂ )

The two difference formulas add the squared standard errors of each group. That is SAXBY with a = 1 and b = minus 1: variances add even when you subtract.

Sample size, both versions

Mean: n = z² σ² / (margin)²
Proportion: n = z² p(1 − p) / (margin)²

Always round up. If you have no pilot estimate of p, use p = 0.5 (most conservative). If you have one, use it: for a 2% response rate, p = 0.5 overstates n by about 12 times. Population size never enters the formula.

Rodgers' p-value sentence, best version

"If the true [difference / proportion / mean] were [reference], there would be a [p]% chance of observing a result at least as far from it as the one in our sample."

Short version ("the difference is due to chance") loses points in a written answer. Below 0.05 is significant at the 5% level; below 0.01 at the 1% level. State the level you used.
